## Getting photos legally

Photos from Google Images are usually copyrighted, so do not republish them without permission. Better sources:

1. **The school's official website** (kautilyavidyalaya.edu.in), which has an About Us page with campus photos.
2. **News articles** from Star of Mysore or The Hindu about the school's events, which often include photos you can ask permission to use.
3. **Photos you take yourself** during a visit, or photos from parents and students with permission.
4. **Free photo sites** such as Unsplash or Pexels, if you use generic photos of swimming pools, playgrounds and classrooms and label them as illustrations.

Rename each photo to the exact filename above (lowercase, no spaces) and put it in the `images` folder. Resize large photos to about 1200 pixels wide before uploading so the page loads quickly.

## Publishing on GitHub Pages

1. Create a new public repository named `BHUVAN` on GitHub.
2. Upload everything in this folder, keeping the subfolders (drag the whole folder, or use `git`).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
4. After about a minute, the site will be live at `https://YOUR-USERNAME.github.io/BHUVAN/`.

Important: keep the file names and folder names exactly as they are, because GitHub Pages is case-sensitive.

## Accuracy note

The facts in this site (founding year, CBSE affiliation, Atal Tinkering Lab, awards) come from public sources such as Wikipedia, the Atal Innovation Mission, and Star of Mysore and Deccan Herald news reports. Some directory websites list different founding years (2004 and 2005), so verify before publishing worldwide. The facility descriptions are general descriptions, not verified claims. Please check them with the school before you publish.
